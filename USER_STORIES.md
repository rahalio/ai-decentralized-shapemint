# Shapemint — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Consortium model owner

- As a model owner, I want to define in-scope behaviours for influence, so that we pay for the changes we actually want.
- As a model owner, I want negative-influence rulings to block payout, so that poisoning is not rewarded.
- As a model owner, I want to pause minting when evaluation drift spikes, so that bad meters do not drain the treasury.

### External contributor / HITL worker

- As a contributor, I want a quantified influence score for my update or label batch, so that my impact is not a matter of opinion.
- As a contributor, I want pre-accepted incentive policy in writing, so that I know what influence is worth before I work.
- As a HITL worker, I want my annotation batches metered like model updates, so that human knowledge is not second-class.

### Consortium auditor

- As an auditor, I want to reproduce influence scores without raw datasets, so that transparency does not equal data exfiltration.
- As an auditor, I want an append-only contribution activity log, so that no middleman silently rewrote history.

### Incentive operations / finance

- As incentive ops, I want automatic payout drafts from influence bands, so that settlement matches policy.
- As finance, I want statements linking scores to amounts, so that the month closes cleanly.

### Compliance

- As a compliance officer, I want competitor-isolated transparency views, so that multi-party participation does not leak trade secrets.
- As a compliance officer, I want privacy-mode contributions that never upload raw training data, so that the privacy problem stays solved while influence is measured.
